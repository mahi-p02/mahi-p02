## 🚀 About Me

I'm **Mahi Priyadarshi**, a **Data Annotator, AI/ML Enthusiast & Competitive Programmer**.  
Currently pursuing **B.Tech CSE at CU Jammu (2024–2028)**, I specialize in **data annotation, AI fundamentals, problem solving, and full stack web development**.

With hands-on experience in **labeling and quality-checking datasets, solving algorithmic problems, and building AI-powered MERN applications**, I'm passionate about turning raw data into intelligent, secure products. My focus is on **clean data pipelines, data structures & algorithms, and scalable full stack development** that help teams build reliable AI systems.

* 🏷️ **Data Annotation** – Labeling and quality-checking text, image, and tabular datasets with tools like Label Studio.  
* 🤖 **AI & Machine Learning** – Python, data preprocessing, ML fundamentals, and AI/LLM API integration.  
* 🧩 **Competitive Programming** – Solving DSA problems in C++.  
* 💻 **Full Stack Development** – Building secure, scalable full stack applications with AI integration, covering frontend, backend, and databases.
